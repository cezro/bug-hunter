# Investigation Record: HostGator LATAM AI Platform Security Evaluation

## 1. Initial Anomaly & Discovery
- **Target Subsystem / Endpoint:** 
  - Frontend: `https://super.hostgator.com.br` (Next.js PWA)
  - Core AI Backend: `https://ai-core.hostgator.com.br/api` (Laravel)
  - Multi-LLM Platform: `https://allpass.hostgator.com.br` (HostGatorGPT)
  - WHMCS SSO & Billing: `https://financeiro.hostgator.com.br` (OAuth 2.0 Authorization Server)
- **Discovery Date:** 2026-10-31
- **Observation:**
  - HostGator LATAM announced a specific priority focus on **AI Agents Section** and **AI-related VPS Features**.
  - Reverse engineering the SuperGator client JavaScript bundle (`_app-55de464cbb88e84e.js`, `594-717cd23cce9a2d8f.js`) revealed an extensive AI Platform Core API exposing 33+ endpoints on `https://ai-core.hostgator.com.br/api` with wildcard CORS (`access-control-allow-origin: *`).
  - Active routes include AI Agent CRUD, RAG training via URL crawling (`/omnichannel/agents/{id}/training`), AWS AppSync IAM session credentials retrieval (`/omnichannel/agents/{id}/credentials`), and customer lead exports (`/api/clients/download`).

---

## 2. Hypothesis & Threat Model
- **Hypothesis 1: SSRF & Cloud Metadata Extraction via RAG Knowledge Crawler**
  - The endpoint `POST /api/omnichannel/agents/{agentId}/training` accepts a `website` parameter to scrape, parse, and embed website content for the agent's knowledge base.
  - Threat Model: Lack of internal IP validation or DNS rebinding protection in the scraper worker allows requests to cloud metadata endpoints (`http://169.254.169.254/latest/meta-data/` or GCP metadata) and internal Kubernetes / Docker network services.
- **Hypothesis 2: BOLA / IDOR on AI Agent AppSync Credentials & Leads Data**
  - The endpoint `GET /api/omnichannel/agents/{agentId}/credentials` returns AWS AppSync IAM credentials (`accessKeyId`, `secretAccessKey`, `sessionToken`) for a given agent.
  - The export endpoint `POST /api/clients/download` filters leads by `agentId`.
  - Threat Model: Inadequate tenant boundary checks between the authenticated JWT token and the `{agentId}` path parameter permit cross-tenant credential theft and exfiltration of customer lead PII.
- **Hypothesis 3: AI Model Tampering & Quota Abuse in Agent Execution**
  - Direct execution via `POST /api/omnichannel/agents/{agentId}/test` and AllPass multi-model gateways allow manipulation of underlying system prompts, model deployment targets, and unbounded token consumption.
